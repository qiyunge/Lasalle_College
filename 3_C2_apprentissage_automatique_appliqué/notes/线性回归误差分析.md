# Bias² + Variance + Noise 推导

在回归问题中，当损失函数是平方误差时，模型的期望测试误差可以分解为：

[
\boxed{
\mathbb{E}\left[(Y-\hat f_D(x))^2\right]
========================================

\operatorname{Bias}^2
+
\operatorname{Variance}
+
\operatorname{Noise}
}
]

注意：

[
\operatorname{Bias}^2
]

表示 **Bias 的平方**，不是 (2\times \operatorname{Bias})。

---

## 1. 数据生成过程

假设真实数据由下面的过程生成：

[
Y=f(x)+\varepsilon
]

其中：

* (f(x))：输入 (x) 对应的真实函数值
* (\varepsilon)：随机噪声
* (Y)：实际观测值

假设噪声满足：

[
\mathbb{E}[\varepsilon]=0
]

[
\operatorname{Var}(\varepsilon)=\sigma^2
]

因为噪声均值为 0，所以：

[
\mathbb{E}[\varepsilon^2]=\sigma^2
]

---

## 2. 不同训练集会产生不同模型

设训练集为 (D)。

使用不同的训练集 (D)，训练得到的模型可能不同，因此模型预测写为：

[
\hat f_D(x)
]

我们希望计算固定输入 (x) 下的期望平方测试误差：

[
\mathbb{E}_{D,\varepsilon}
\left[
(Y-\hat f_D(x))^2
\right]
]

这里的期望针对两个随机因素：

1. 训练集 (D) 的随机性
2. 测试数据噪声 (\varepsilon) 的随机性

---

## 3. 代入真实数据模型

因为：

[
Y=f(x)+\varepsilon
]

所以：

[
\mathbb{E}
\left[
(Y-\hat f_D(x))^2
\right]
=======

\mathbb{E}
\left[
(f(x)+\varepsilon-\hat f_D(x))^2
\right]
]

将平方展开：

# [

\mathbb{E}
\left[
(f(x)-\hat f_D(x))^2
+
2\varepsilon(f(x)-\hat f_D(x))
+
\varepsilon^2
\right]
]

利用期望的线性性质：

# [

\mathbb{E}_D
\left[
(f(x)-\hat f_D(x))^2
\right]
+
2\mathbb{E}
\left[
\varepsilon(f(x)-\hat f_D(x))
\right]
+
\mathbb{E}[\varepsilon^2]
]

---

## 4. 消去噪声交叉项

因为测试噪声 (\varepsilon) 与训练得到的模型 (\hat f_D(x)) 相互独立，并且：

[
\mathbb{E}[\varepsilon]=0
]

所以：

[
\mathbb{E}
\left[
\varepsilon(f(x)-\hat f_D(x))
\right]
=0
]

同时：

[
\mathbb{E}[\varepsilon^2]
=========================

\sigma^2
]

因此：

[
\mathbb{E}
\left[
(Y-\hat f_D(x))^2
\right]
=======

\mathbb{E}_D
\left[
(f(x)-\hat f_D(x))^2
\right]
+
\sigma^2
]

其中：

[
\sigma^2
]

就是数据中的不可约噪声：

[
\operatorname{Noise}=\sigma^2
]

---

## 5. 定义模型的平均预测

对所有可能的训练集 (D)，模型预测的平均值定义为：

[
\bar f(x)
=========

\mathbb{E}_D[\hat f_D(x)]
]

在误差中加上再减去 (\bar f(x))：

[
f(x)-\hat f_D(x)
================

f(x)-\bar f(x)
+
\bar f(x)-\hat f_D(x)
]

因此：

[
\mathbb{E}_D
\left[
(f(x)-\hat f_D(x))^2
\right]
]

可以写成：

[
\mathbb{E}_D
\left[
\left(
f(x)-\bar f(x)
+
\bar f(x)-\hat f_D(x)
\right)^2
\right]
]

---

## 6. 展开平方

使用：

[
(a+b)^2=a^2+2ab+b^2
]

得到：

# [

(f(x)-\bar f(x))^2
]

[
+
2(f(x)-\bar f(x))
\mathbb{E}_D
\left[
\bar f(x)-\hat f_D(x)
\right]
]

[
+
\mathbb{E}_D
\left[
(\bar f(x)-\hat f_D(x))^2
\right]
]

---

## 7. 交叉项等于 0

因为：

[
\bar f(x)
=========

\mathbb{E}_D[\hat f_D(x)]
]

所以：

[
\mathbb{E}_D
\left[
\bar f(x)-\hat f_D(x)
\right]
]

# [

## \bar f(x)

\mathbb{E}_D[\hat f_D(x)]
]

# [

\bar f(x)-\bar f(x)
]

[
=0
]

因此交叉项消失：

[
2(f(x)-\bar f(x))
\mathbb{E}_D
\left[
\bar f(x)-\hat f_D(x)
\right]
=0
]

于是：

[
\mathbb{E}_D
\left[
(f(x)-\hat f_D(x))^2
\right]
=======

(f(x)-\bar f(x))^2
+
\mathbb{E}_D
\left[
(\hat f_D(x)-\bar f(x))^2
\right]
]

---

## 8. 识别 Bias 和 Variance

### Bias

Bias 定义为模型平均预测与真实函数之间的差：

[
\operatorname{Bias}(\hat f(x))
==============================

\mathbb{E}_D[\hat f_D(x)]-f(x)
]

也就是：

[
\operatorname{Bias}(\hat f(x))
==============================

\bar f(x)-f(x)
]

因此 Bias 的平方为：

[
\operatorname{Bias}^2
=====================

(\bar f(x)-f(x))^2
]

由于平方会消除正负号：

[
(\bar f(x)-f(x))^2
==================

(f(x)-\bar f(x))^2
]

---

### Variance

Variance 表示模型预测随着训练集变化而变化的程度：

[
\operatorname{Var}_D(\hat f_D(x))
=================================

\mathbb{E}_D
\left[
\left(
\hat f_D(x)-\mathbb{E}_D[\hat f_D(x)]
\right)^2
\right]
]

因为：

[
\bar f(x)=\mathbb{E}_D[\hat f_D(x)]
]

所以：

[
\operatorname{Variance}
=======================

\mathbb{E}_D
\left[
(\hat f_D(x)-\bar f(x))^2
\right]
]

---

## 9. 最终结果

将 Bias、Variance 和 Noise 合并：

[
\boxed{
\mathbb{E}_{D,\varepsilon}
\left[
(Y-\hat f_D(x))^2
\right]
=======

\left(
\mathbb{E}_D[\hat f_D(x)]-f(x)
\right)^2
+
\mathbb{E}_D
\left[
\left(
\hat f_D(x)-\mathbb{E}_D[\hat f_D(x)]
\right)^2
\right]
+
\sigma^2
}
]

也就是：

[
\boxed{
\text{Expected Test Error}
==========================

\operatorname{Bias}^2
+
\operatorname{Variance}
+
\operatorname{Noise}
}
]

---

## 10. 直观解释

### Bias²

[
\operatorname{Bias}^2
]

表示模型的平均预测与真实规律之间相差多远。

Bias 大通常说明模型过于简单，容易出现欠拟合。

---

### Variance

[
\operatorname{Variance}
]

表示更换训练集之后，模型预测变化有多大。

Variance 大通常说明模型对训练数据过于敏感，容易出现过拟合。

---

### Noise

[
\operatorname{Noise}=\sigma^2
]

表示数据本身无法预测的随机性。

即使找到了真实函数 (f(x))，噪声仍然存在，因此它也叫：

[
\text{Irreducible Error}
]

即不可约误差。

---

## 11. 最核心的数学技巧

整个推导的关键，是在误差中加上再减去模型的平均预测：

[
f(x)-\hat f_D(x)
]

写成：

[
f(x)-\mathbb{E}_D[\hat f_D(x)]
+
\mathbb{E}_D[\hat f_D(x)]
-------------------------

\hat f_D(x)
]

第一部分产生 Bias：

[
f(x)-\mathbb{E}_D[\hat f_D(x)]
]

第二部分产生 Variance：

[
\mathbb{E}_D[\hat f_D(x)]-\hat f_D(x)
]

交叉项因为均值定义而等于 0。

因此最终得到：

[
\boxed{
\text{Error}
============

\text{Bias}^2
+
\text{Variance}
+
\text{Noise}
}
]
