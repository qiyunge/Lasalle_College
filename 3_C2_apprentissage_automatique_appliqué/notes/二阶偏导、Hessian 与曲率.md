# 二阶偏导、Hessian 与曲率

## 1. 核心结论

二阶导数不严格等于几何曲率。

更准确地说：

> **二阶导数描述斜率变化的快慢，是曲率的核心来源；真正的几何曲率还需要考虑曲线当前的倾斜程度。**

在优化中，人们常把二阶导数或 Hessian 称为“曲率信息”，但这里的“曲率”通常是局部二阶变化意义上的曲率，而不是严格的微分几何曲率。

---

## 2. 一阶导数描述斜率

对于一维函数：

[
y=f(x)
]

一阶导数为：

[
f'(x)=\frac{dy}{dx}
]

它描述函数在当前位置的切线斜率。

也就是说，一阶导数告诉我们：

> 当 (x) 稍微变化时，函数值 (f(x)) 大约变化多少。

函数在 (x) 附近的一阶近似为：

[
f(x+\Delta x)
\approx
f(x)+f'(x)\Delta x
]

这相当于用切线代替原函数。

---

## 3. 二阶导数描述斜率如何变化

二阶导数为：

[
f''(x)=\frac{d}{dx}f'(x)
]

它表示：

> 一阶导数，也就是切线斜率，随着 (x) 的变化而变化得有多快。

因此：

* (f''(x)>0)：斜率逐渐增大，曲线向上弯；
* (f''(x)<0)：斜率逐渐减小，曲线向下弯；
* (f''(x)=0)：斜率局部不变，曲线局部可能接近直线；
* (|f''(x)|) 较大：斜率变化较快，函数弯曲得更明显。

所以二阶导数能够描述函数的局部弯曲程度。

---

## 4. 为什么二阶导数能表示弯曲

函数的二阶泰勒展开为：

[
f(x+\Delta x)
\approx
f(x)
+
f'(x)\Delta x
+
\frac12f''(x)(\Delta x)^2
]

其中：

[
f(x)+f'(x)\Delta x
]

是切线给出的线性近似。

而：

[
\frac12f''(x)(\Delta x)^2
]

描述真实函数偏离切线的程度。

因此：

> 一阶导数描述函数沿切线如何变化，二阶导数描述函数如何偏离切线并发生弯曲。

这就是二阶导数被称为“曲率信息”的原因。

---

## 5. 几何曲率的严格定义

对于一条平面曲线，曲率的严格定义是：

[
\boxed{
\kappa
======

\left|
\frac{d\theta}{ds}
\right|
}
]

其中：

* (\theta) 是切线方向与 (x) 轴的夹角；
* (s) 是沿曲线测量的弧长；
* (\frac{d\theta}{ds}) 表示沿曲线每移动一个单位长度，切线方向改变多少。

因此，几何曲率真正衡量的是：

> 曲线方向变化得有多快。

曲率越大，转弯越急。

曲率越小，曲线越平缓。

---

## 6. 函数图像的曲率公式

对于函数图像：

[
y=f(x)
]

其曲率为：

[
\boxed{
\kappa
======

\frac{|f''(x)|}
{\left(1+\left(f'(x)\right)^2\right)^{3/2}}
}
]

如果需要保留弯曲方向，可以使用带符号曲率：

[
\kappa_s
========

\frac{f''(x)}
{\left(1+\left(f'(x)\right)^2\right)^{3/2}}
]

其中：

* (f''(x)) 描述斜率变化；
* 分母修正当前曲线的倾斜程度；
* 绝对值保证几何曲率非负。

---

## 7. 曲率公式的推导

因为切线斜率满足：

[
\tan\theta=f'(x)
]

所以：

[
\theta=\arctan f'(x)
]

对 (x) 求导：

[
\frac{d\theta}{dx}
==================

\frac{f''(x)}
{1+\left(f'(x)\right)^2}
]

另一方面，曲线弧长满足：

[
ds
==

\sqrt{dx^2+dy^2}
]

由于：

[
dy=f'(x),dx
]

因此：

[
ds
==

\sqrt{1+\left(f'(x)\right)^2},dx
]

于是：

[
\frac{ds}{dx}
=============

\sqrt{1+\left(f'(x)\right)^2}
]

根据链式法则：

[
\frac{d\theta}{ds}
==================

\frac{d\theta/dx}{ds/dx}
]

代入得到：

[
\frac{d\theta}{ds}
==================

\frac{
\dfrac{f''(x)}
{1+(f'(x))^2}
}{
\sqrt{1+(f'(x))^2}
}
]

所以：

[
\frac{d\theta}{ds}
==================

\frac{f''(x)}
{\left(1+(f'(x))^2\right)^{3/2}}
]

取绝对值后：

[
\boxed{
\kappa
======

\frac{|f''(x)|}
{\left(1+(f'(x))^2\right)^{3/2}}
}
]

---

## 8. 为什么不能直接把 (f''(x)) 当成曲率

二阶导数：

[
f''(x)
]

描述的是：

> 斜率相对于横坐标 (x) 的变化率。

但严格的几何曲率描述的是：

> 切线方向相对于曲线实际弧长 (s) 的变化率。

因此，二阶导数会受到坐标尺度和曲线倾斜程度的影响。

例如，在曲线非常陡的地方，即使 (f''(x)) 较大，实际沿曲线每走一个单位距离时，方向变化未必同样大。

所以曲率公式中需要分母：

[
\left(1+(f'(x))^2\right)^{3/2}
]

来消除倾斜程度带来的影响。

---

## 9. 驻点附近为什么可以近似认为 (f'') 就是曲率

在驻点 (x^*) 附近：

[
f'(x^*)=0
]

此时曲率为：

[
\kappa(x^*)
===========

\frac{|f''(x^*)|}
{\left(1+0^2\right)^{3/2}}
]

所以：

[
\boxed{
\kappa(x^*)=|f''(x^*)|
}
]

因此，在极值点或水平切线附近，二阶导数的绝对值就等于几何曲率。

这也是为什么在优化问题中，人们常直接把二阶导数称为曲率。

---

## 10. 曲率半径

曲率半径定义为：

[
\boxed{
R=\frac{1}{\kappa}
}
]

含义是：

> 用一个圆来近似曲线在当前点附近的形状，这个圆的半径就是曲率半径。

因此：

* 曲率 (\kappa) 越大，曲率半径 (R) 越小，转弯越急；
* 曲率 (\kappa) 越小，曲率半径 (R) 越大，曲线越平缓；
* 直线的曲率为 0，对应曲率半径趋于无穷大。

---

## 11. 多变量函数中的二阶偏导

对于多变量函数：

[
f(x_1,x_2,\ldots,x_n)
]

可以对不同变量求二阶偏导。

例如二维函数：

[
f(x,y)
]

包含以下二阶偏导：

[
\frac{\partial^2f}{\partial x^2}
]

[
\frac{\partial^2f}{\partial y^2}
]

以及混合偏导：

[
\frac{\partial^2f}{\partial x\partial y}
]

这些二阶偏导组成 Hessian 矩阵：

[
H(x,y)
======

\begin{bmatrix}
\frac{\partial^2f}{\partial x^2}
&
\frac{\partial^2f}{\partial x\partial y}
\
\frac{\partial^2f}{\partial y\partial x}
&
\frac{\partial^2f}{\partial y^2}
\end{bmatrix}
]

---

## 12. Hessian 描述什么

梯度：

[
\nabla f(x)
]

描述函数在当前位置的一阶变化方向。

Hessian：

[
H(x)=\nabla^2f(x)
]

描述梯度本身如何变化。

因此可以理解为：

* 梯度描述坡度；
* Hessian 描述坡度场如何变化；
* Hessian 给出多变量函数的局部二阶形状。

对于足够光滑的函数，Hessian 通常是对称矩阵：

[
\frac{\partial^2f}{\partial x_i\partial x_j}
============================================

\frac{\partial^2f}{\partial x_j\partial x_i}
]

---

## 13. 沿任意方向的二阶变化

设 (d) 是一个方向向量，考虑一维函数：

[
\phi(t)=f(x+td)
]

它表示从点 (x) 出发，沿方向 (d) 移动时，目标函数如何变化。

一阶导数为：

[
\phi'(0)
========

\nabla f(x)^Td
]

这表示沿方向 (d) 的一阶变化率。

二阶导数为：

[
\boxed{
\phi''(0)
=========

d^TH(x)d
}
]

它表示函数沿方向 (d) 的二阶变化程度。

因此：

* (d^THd>0)：函数沿该方向向上弯；
* (d^THd<0)：函数沿该方向向下弯；
* (d^THd=0)：沿该方向没有明显的二阶弯曲；
* (|d^THd|) 越大：该方向的二阶变化越强。

所以 Hessian 不是一个单独的曲率值，而是：

> 描述函数在不同方向上分别如何弯曲。

---

## 14. Hessian 的特征值与局部形状

在驻点：

[
\nabla f(x^*)=0
]

可以通过 Hessian 的特征值判断局部形状。

### 所有特征值都为正

[
\lambda_i>0
]

Hessian 正定，函数在所有方向上都向上弯，因此通常是局部最小值。

### 所有特征值都为负

[
\lambda_i<0
]

Hessian 负定，函数在所有方向上都向下弯，因此通常是局部最大值。

### 有正有负

Hessian 不定，函数在某些方向向上弯，在另一些方向向下弯，因此是鞍点。

---

## 15. 优化中的“曲率”和几何曲率不同

在优化中，说：

> Hessian 描述曲率。

通常不是指曲面的严格微分几何曲率，而是指：

> 目标函数相对于局部线性近似的二阶变化程度。

优化更关心的是：

* 某个方向上函数变化有多快；
* 当前区域有多陡或多平；
* 应该使用多大的更新步长；
* 各个参数方向的尺度是否一致。

因此，优化中的“曲率”主要由：

[
d^THd
]

或 Hessian 的特征值表示。

---

## 16. 梯度下降与二阶方法

梯度下降使用一阶信息：

[
x_{k+1}
=======

x_k-\eta\nabla f(x_k)
]

其中学习率 (\eta) 通常需要人工设置。

牛顿法同时使用梯度和 Hessian：

[
x_{k+1}
=======

x_k-H(x_k)^{-1}\nabla f(x_k)
]

Hessian 会根据不同方向上的二阶变化，对梯度进行缩放。

因此：

* 曲率大的方向，步长通常应更小；
* 曲率小的方向，步长可以更大；
* 不同参数方向可以使用不同的有效步长。

这使牛顿法能够利用目标函数的局部形状，而不仅仅依靠下降方向。

---

## 17. 一个直观类比

可以把函数图像看成地形：

| 数学量                     | 几何含义             |
| ----------------------- | ---------------- |
| (f(x))                  | 当前高度             |
| (f'(x)) 或 (\nabla f(x)) | 当前坡度和最陡方向        |
| (f''(x)) 或 Hessian      | 坡度如何变化、地形如何弯曲    |
| (\kappa)                | 曲线方向随弧长变化的严格几何曲率 |

因此可以说：

> 函数值告诉我们在哪里，梯度告诉我们往哪里走，二阶导数告诉我们前方地形如何变化。

---

## 18. 最准确的关系

一维情况下：

[
\boxed{
f'(x)=\text{切线斜率}
}
]

[
\boxed{
f''(x)=\text{斜率相对于 }x\text{ 的变化率}
}
]

[
\boxed{
\kappa
======

\frac{|f''(x)|}
{\left(1+(f'(x))^2\right)^{3/2}}
}
]

多变量情况下：

[
\boxed{
H=\nabla^2f
}
]

而沿方向 (d) 的二阶变化为：

[
\boxed{
d^THd
}
]

---

## 19. 一句话总结

> **二阶导数不是一般意义下的严格几何曲率，但它描述了函数偏离局部切线的二阶程度，是曲率的核心信息。**

在驻点附近：

[
f'(x^*)=0
]

有：

[
\kappa(x^*)=|f''(x^*)|
]

而在多变量优化中，Hessian 通过：

[
d^THd
]

描述函数沿不同方向的局部二阶弯曲程度。
