## 📚 Topics Covered

### Statistical Analysis
- **Confidence Intervals**: Using t-distribution and normal distribution
- **Hypothesis Testing**: Statistical significance testing
- **Descriptive Statistics**: Data summarization and analysis
- **Correlation Analysis**: Understanding relationships between variables

### Machine Learning & Regression
- **Simple Linear Regression**: Modeling linear relationships between variables
- **Multiple Linear Regression**: Regression with multiple predictors
- **Polynomial Regression**: Non-linear relationship modeling
- **Naive Bayes**: Probabilistic classification algorithm

### Data Analysis & Visualization
- **Data Types**: Understanding and working with different data types
- **Data Visualization**: Creating meaningful visual representations
- **Feature Scaling**: Standardization and normalization techniques
- **Train-Test Split**: Model validation techniques

## 🛠️ Technologies Used

- **Python**: Primary programming language
- **Libraries**:
  - `NumPy`: Numerical computing
  - `Pandas`: Data manipulation and analysis
  - `Matplotlib`: Data visualization
  - `Scikit-learn`: Machine learning algorithms
  - `SciPy`: Scientific computing and statistical functions

## 📊 Datasets

The `data/` folder contains various datasets used for statistical analysis and machine learning:
- **Salary Data**: For regression analysis and prediction models
- **Startup Data**: 50 startup companies with various metrics
- **Position Salaries**: Hierarchical position and salary information
