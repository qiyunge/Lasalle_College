# 缺失机制（Missing Mechanisms）总结：MCAR vs MAR vs MNAR

目标：

理解为什么数据会缺失，并选择合理的缺失值处理策略。

核心问题：

不是：

“缺失值应该填什么？”

而是：

“为什么缺失？”

---

# 1 MCAR — Missing Completely At Random

中文：

完全随机缺失

定义：

缺失发生与任何变量无关。

数学：

# P(Missing | X)

P(Missing)

即：

是否缺失
⊥
所有数据

---

示例

调查问卷：

| 年龄  |
| --- |
| 20  |
| 30  |
| NaN |

原因：

* 网络错误
* 数据丢失
* 用户随机跳过

不是：

* 老人更容易不填
* 男性更容易不填

---

特点

缺失：

随机

观察样本：

≈

真实样本

---

常见处理

```python
dropna()

fillna(mean)

fillna(median)
```

---

风险

较低。

通常不会引入明显偏差。

---

判断方法

检查：

缺失是否与其它变量相关。

例如：

```python
df.groupby(
df["Age"].isna()
).mean()
```

若无明显差异：

可能 MCAR。

---

# 2 MAR — Missing At Random

中文：

条件随机缺失

定义：

缺失依赖其它变量。

数学：

P(
Missing
|
X_other
)

即：

缺失
←
其它字段

---

示例

收入缺失：

学历越高越不愿填写。

即：

Education
→
Income Missing

---

示例

| Education | Income |
| --------- | ------ |
| Low       | 100    |
| High      | NaN    |

---

特点

缺失：

可被其它变量解释。

观察：

存在偏差。

但：

可建模恢复。

---

常见处理

按组填充：

```python
groupby()
.transform()
```

例：

```python
df["Income"] = (
df.groupby(
"Education"
)
["Income"]
.transform(
lambda s:
s.fillna(
s.median()
)
)
)
```

高级：

* KNN
* Iterative
* Regression

---

风险

中。

错误插补会改变条件分布。

---

判断方法

检查：

```python
df.groupby(
"Education"
)["Income"]
.apply(
lambda s:
s.isna().mean()
)
```

若不同组差异明显：

可能 MAR。

---

# 3 MNAR — Missing Not At Random

中文：

非随机缺失

定义：

缺失依赖字段真实值。

数学：

P(
Missing
|
X_missing
)

即：

缺失
←
自身真实值

---

示例

收入越高：

越不愿填写。

收入：

100
1000
NaN

实际：

NaN
可能是
10000

---

示例

贷款：

Credit_History=NaN

可能：

没有信用记录。

---

特点

缺失：

本身就是信息。

不能简单补值。

---

常见处理

保留缺失信息：

```python
df[
"missing_flag"
]=(
df[
"Income"
]
.isna()
)
```

再：

```python
fillna(0)
```

或：

```python
fillna("Unknown")
```

---

风险

最高。

错误填补容易导致模型严重偏差。

---

判断方法

新增：

```python
isna()
```

比较：

```python
df.groupby(
"missing_flag"
).mean()
```

若差异显著：

可能 MNAR。

结合业务判断。

---

# 三者对比

| 项目     | MCAR  | MAR  | MNAR |
| ------ | ----- | ---- | ---- |
| 依赖自身   | 否     | 否    | 是    |
| 依赖其它变量 | 否     | 是    | 可能   |
| 缺失有信息  | 否     | 弱    | 强    |
| 容易处理   | 高     | 中    | 低    |
| 推荐     | 均值/删除 | 条件插补 | 保留缺失 |

---

# 判断口诀

问：

为什么缺？

服务器坏：

→ MCAR

某些群体更容易缺：

→ MAR

真实值越特殊越容易缺：

→ MNAR

---

一句话总结

MCAR：

随机丢。

MAR：

别人导致丢。

MNAR：

自己决定丢。
