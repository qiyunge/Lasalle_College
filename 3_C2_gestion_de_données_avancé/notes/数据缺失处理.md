# Missing Value Handling（缺失值处理）

目标：

估计缺失值，同时尽量不破坏真实数据生成过程（Data Generating Process）。

核心流程：

发现缺失
↓
判断缺失机制
↓
判断变量类型
↓
判断数据分布
↓
选择插补方法
↓
评估模型影响

---

# Step 1 判断缺失机制（Missing Mechanism）

这是最重要的一步。

问题：

为什么缺失？

## 1. MCAR
Missing Completely At Random

缺失与任何变量无关。

例：

- 网络故障
- 用户随机漏填

形式：

P(Missing | X)=P(Missing)

特点：

- 数据仍近似原分布
- 可直接插补

推荐：

- dropna()
- mean()
- median()

---

## 2. MAR
Missing At Random

缺失依赖其他变量。

例：

高收入人群更不愿填收入。

形式：

P(Missing|X1,X2)

特点：

- 不能直接全局均值
- 应利用条件信息

推荐：

groupby()

例：

```python
df["Income"] = (
    df.groupby("Education")
      ["Income"]
      .transform(
          lambda s:
          s.fillna(
              s.median()
          )
      )
)
3. MNAR

Missing Not At Random

缺失本身就是信息。

例：

CoapplicantIncome=NaN

代表：

没有共同申请人。

特点：

不能简单插补。

推荐：

保留缺失信息：

df["Income_missing"] = (
    df["Income"]
      .isna()
)

再：

fillna(0)

一句话总结

缺失值处理不是填空。

而是在假设：

真实值 ≈ 某种条件下的概率估计。

即：

估计：

P(X_true | X_obs)
